## ⚡ 我在做什么

- 🔭 **目前专注 AI 领域** — AI Agent 应用、微信 AI 接入、AI Skill 与 LLM 工具链（**wechat-channel**、**china-color-palette**）
- 🖥️ **终端与效率工具** — SSH / SFTP 连接管理、系统监控、Git 提交历史生成，把运维琐事装进一个轻量桌面端（**shelx**、**fake-commit**）
- 📦 **跨平台桌面应用** — 用 Tauri / Electron 打造轻量、即开即用的工具型应用（**transpop**、**balance-monitor**）
- 🤖 **AI × 微信生态** — Agent 无关的微信 ilink 消息通道库，一行回调即可让任意 AI 接入微信（**wechat-channel**）
- 🔐 **安全与认证** — TOTP / HOTP 双因素认证、API Key 本地加密存储，安全优先（**totp-auth**、**balance-monitor**）
- 🎨 **设计与文化** — 中国传统色彩配色 Skill，让 AI 读懂传统审美（**china-color-palette**）
- ⚙️ **全栈与运维** — Java / Spring Boot 后端服务，Redis / MySQL / PostgreSQL 存储，Docker + Linux 部署
